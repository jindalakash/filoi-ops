# Proposal template bank

Drop your existing, successful proposals here — they become the reference
library for the **Proposal engine (Phase 3)**.

| Folder | What to put in it |
|---|---|
| `technical/` | Past technical proposals (.docx preferred, PDF ok) |
| `financial/` | Past financial proposals / budget sheets (.docx / .xlsx) |
| `cvs/` | Expert CVs in the formats clients ask for (WHO, UNICEF, World Bank…) |
| `company/` | Company profile, registration, PAN/GST certificates, experience list |

Naming tip: `CLIENT_year_short-title.docx`, e.g. `WHO_2025_dhis2-assessment.docx`.

This folder is excluded from git so client documents never leave your machine.
